# Furigane
Furigana for Minecraft

This project adds furigana to Minecraft and favourite mods!

You can use this packs without mods, but using Rubi or Amber (Rubi's Fork) is highly recommended!

## Furigana is made by automated tools and AI so it can contain errors! If you find any, create an issue!

Supports:
- Terralith
- Sodium
- Shulkerbox Tooltip
- Reeses Sodium Options
- Nature Compass
- Mod Menu
- Lambdynlights
- JEI
- JADE
- Iris
- CarryOn
- BetterAdvencements

Want support for something? Create an issue!
